## Attribution Requirement

All images on this website require attribution. The website complies by:

1. **Linking directly to source:** Each image links to its Wikimedia Commons page
2. **Displaying license:** License type and link shown on `/sources` page
3. **Showing authors:** Original creators credited where available on Wikimedia
4. **Documenting usage:** Each landmark includes source documentation

Attribution text example:
```
Image: Mazar-e-Quaid (Source: Wikimedia Commons, License: CC BY-SA 4.0)
[Link to source]
```

## Reusing Content

If you reuse images from this website:

1. **Retain the original license** (CC BY-SA 4.0 or 3.0)
2. **Link to original source** (Wikimedia Commons)
3. **Credit the original author** (as shown on Wikimedia)
4. **Indicate if modified** (if you edited the image)
5. **Use compatible license** (if distributing, use same CC license)

Example attribution:
```
"Mazar-e-Quaid" by [Author Name]
Licensed under CC BY-SA 4.0
https://commons.wikimedia.org/wiki/File:Mazar-e-Quaid_Karachi.jpg
```
