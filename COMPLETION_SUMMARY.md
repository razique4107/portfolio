## 🚀 HOW TO RUN

### **Step 1: Create .env file**
Copy content from `.env.example` into new `.env` file

### **Step 2: Start Docker**
```
docker compose up -d
```

### **Step 3: Install dependencies**
```
npm install
```

### **Step 4: Setup database**
```
npm run db:migrate
npm run db:seed
```

### **Step 5: Start server**
```
npm run dev
```

### **Step 6: Open browser**
Visit: `http://localhost:3000`

✅ **Website is running!**
