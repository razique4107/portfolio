  ## UI/UX Pro Max Skill

  The UI/UX Pro Max skill is an AI-powered design intelligence toolkit with:

  - **84+ searchable UI styles** (glassmorphism, minimalism, brutalism, soft UI, neumorphism, etc.)
  - **192color palettes** organized by product type and mood
  - **74 font pairings** from Google Fonts with accessibility guidance
  - **98 UX best practices** and anti-patterns
  - **25 chart types** with library recommendations
  - Support for **22 tech stacks** (HTML/Tailwind, React, Next.js, Vue, Astro, etc.)

  ### When to Use It

  - Choosing a new color palette or updating the current purple/pink gradient
  - Improving typography (font families, sizing, hierarchy)
  - Redesigning sections (hero, cards, navigation, footer)
  - Adding animations or transitions
  - Ensuring accessibility compliance
  - Exploring different design systems
